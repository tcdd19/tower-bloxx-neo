# 🏗️ Tower Bloxx Neo (摩天大楼：重塑版)

经典诺基亚盖楼游戏《摩天大楼 (Tower Bloxx)》的高清 HTML5 重制版！支持物理摆动、楼体晃动、连击加成、音效合成与手机触觉震动。

## ✨ 核心特性

- 🏢 **经典复刻与升级**：保留原始物理摆钩盖楼玩法，支持偏心晃动物理与连锁反应。
- 🎨 **双主题无缝切换**：在 **赛博霓虹 (Modern Neon)** 与 **诺基亚复古绿 (Retro 3310)** 主题间自由切换。
- 🎵 **实时合成音效**：基于 Web Audio API 动态生成游戏声效，Combo 连击随段位自动升高音调！
- 📳 **触觉震动反馈**：全面集成 Mobile Vibration API，对普通落地、Perfect 对齐与扣血赋予不同震动反馈。
- 🏙️ **渐进式背景与居民系统**：随着楼层不断拔高，背景从黄昏公园切换至万里晴空、平流层乃至浩瀚太空；实时统计大楼入住居民人数。
- 💥 **楼体倾塌与红旗尖顶**：游戏结束触发全屏物理碎片倒塌动画，顶部配有精致的北欧小红尖顶与金旗。
- 📱 **全平台自适应**：完美适配 PC 浏览器与 iOS / Android 移动端触摸操作。

## 🎮 操作说明

| 操作 | 按键 / 手势 |
| :--- | :--- |
| **释放楼层** | 点击屏幕 / `Space` / `Enter` / `↓` / `S` |
| **暂停 / 继续** | `Esc` / `P` 键 |
| **切换主题** | 点击“游戏设置”中的主题选项 |
